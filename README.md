# Urban Scooter — Web, Mobile & API Testing

## Project Overview
This project demonstrates manual software testing of the Urban Scooter application, completed during my TripleTen Quality Assurance training.

The project focused on validating web and Android application functionality, testing REST API endpoints, and documenting software defects.

## Technologies and Tools
- Postman
- Jira
- Android Studio
- Chrome and Opera
- REST APIs and JSON

## Testing Activities
1. Designed and executed manual test cases
2. Performed functional and regression testing
3. Tested web application functionality
4. Tested Android application functionality
5. Validated REST API requests and responses
6. Used boundary-value analysis and equivalence partitioning
7. Documented defects in Jira

## Testing Areas

### Web Application Testing
- Form validation
- Required fields
- Boundary values
- Positive and negative test scenarios

### Mobile Application Testing
- Android application functionality
- Notification behavior
- User interface validation

### API Testing
- REST API endpoint validation
- POST and DELETE requests
- HTTP status codes
- JSON response validation
